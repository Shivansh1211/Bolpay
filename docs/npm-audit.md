`react-router-dom` 6.30.6 is a direct production dependency; npm reports its vulnerability through `react-router`. Vite and esbuild are development/build dependencies (`dev: true` in the lockfile). The static output served by nginx/Vercel does not include the Vite or esbuild server.

No vulnerability was auto-fixed. The audit’s available fixes cross major versions (React Router 6 to 7 and Vite 5 to 8); those changes need a deliberate migration and browser/security review. No `npm audit fix --force` was run. Added the lockfile and changed the frontend Docker build to `npm ci` so future audits and builds use the same resolved tree. Re-run `npm audit` after a reviewed major-version migration and before deployment.
